# deeeecomp

**Status: In development**

Living soil layers, water, temperature, decay, and nutrient state are being developed for eeeearth local scenes. Its work includes dead leaves and wood, soil organic matter, and nitrogen. This public repository is a project summary; implementation and data are not published here.

Learn the science in the [Earth systems guide](https://github.com/eeeearth/eeeearth/tree/main/docs/earth-systems), or watch the [live stream](https://www.youtube.com/@jt55401/live). The simulation covers local scenes and does not model every Earth system.
